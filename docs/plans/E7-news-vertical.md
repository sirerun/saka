# E7 -- News Vertical

Acceptance: callers can search news results distinct from general web results.
fidelity: executable

Decision rationale: docs/adr/003-search-verticals.md. Source: GDELT DOC 2.0
API (founder decision, 2026-08-29) -- genuinely free, no API key or
registration required, full-text keyword search filterable by date range,
country, and language, JSON output, 7 years of indexed news
(https://blog.gdeltproject.org/gdelt-doc-2-0-api-debuts/). Chosen over
SearXNG's news category per David's stated preference for a dedicated news
API when a free one exists.
